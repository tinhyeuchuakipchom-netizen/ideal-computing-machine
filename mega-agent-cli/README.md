# Mega Agent CLI

Một công cụ AI Agent siêu mạnh mẽ tích hợp CLI giao diện cực đẹp (Sử dụng Ink, Clack Prompts). Hỗ trợ nhiều model, hoạt động tự trị và khả năng deep coding, bypass full file system, đốt token để tối ưu suy luận.

## Tính năng

- **Quản lý đa model**: Hỗ trợ Kilo Code, Qwen, Gemini (Chuẩn OpenAI-compatible).
- **Core Agent Full Permission**: Đọc, ghi file, thực thi bash.
- **Deep Coding Loop**: Ép model suy luận sâu với token chain-of-thought trước khi thực thi lệnh.
- **Giao diện cực đẹp**: Gradient, Boxen, Chalk kết hợp với TUI của Ink.

## Hướng dẫn
Chạy lệnh "npm run build" rồi chạy "node dist/index.js" để khởi động.
